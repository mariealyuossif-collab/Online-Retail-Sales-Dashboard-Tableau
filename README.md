# 📊 Online Retail Sales Analysis Dashboard

Welcome to the **Online Retail Sales Analysis** project! This repository contains a professional, interactive Business Intelligence dashboard built using **Tableau** to analyze global retail transaction data and uncover key business insights.

---

## 🚀 Project Overview
This project explores an online retail dataset to track sales performance, understand customer purchasing habits across different countries, and evaluate product-level demand. The goal is to transform raw data into actionable visual insights for better business decision-making.

---

## 📈 Key Performance Indicators (KPIs)
* **Total Sales ($9,747,748):** Calculated using a custom calculated field (`Quantity * Unit Price`) to measure total revenue generation.
* **Total Quantity (5,176,450):** Highlights the overall volume of items sold across all transactions.

---

## 📊 Dashboard Visualizations & Insights
1. **Geographic Map:** Visualizes global sales distribution and quantity concentrations across different countries, allowing interactive filtering.
2. **Top Countries by Quantity:** Ranks countries by performance, highlighting that the United Kingdom leads total sales and volume significantly.
3. **Top 10 Products:** Identifies best-selling products by quantity to recognize high-demand inventory.
4. **Monthly Sales Trend:** A time-series line chart tracking month-over-month sales progression and identifying peak performance periods in 2011.

---

## 🛠️ Tools & Technologies Used
* **Tableau Public:** Data visualization, interactive dashboards, grid-based layout design, and global filter actions.
* **Calculated Fields:** Custom formula creation for revenue tracking.
